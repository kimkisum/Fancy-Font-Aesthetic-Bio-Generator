# ✨ Fancy Font & Aesthetic Bio Generator

> Transform your plain text into stunning fancy fonts and aesthetic bios instantly — no sign-up required.

---

## 🚀 Features

- **100+ Fancy Font Styles** — Unicode-based font transformations (bold, italic, cursive, bubble, etc.)
- **Aesthetic Bio Templates** — Ready-made templates for Instagram, TikTok, Twitter, and more
- **One-Click Copy** — Copy your styled text instantly
- **Free & No Login** — Just open and use

---

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel

---

## 📦 Getting Started

```bash
git clone https://github.com/kimkisum/Fancy-Font-Aesthetic-Bio-Generator.git
cd Fancy-Font-Aesthetic-Bio-Generator
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
